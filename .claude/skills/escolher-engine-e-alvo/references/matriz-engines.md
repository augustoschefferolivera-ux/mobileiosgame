## Evidências por engine

**SwiftUI + SpriteKit.** SpriteKit não aparece deprecado nos metadados da Apple (iOS 7+, sem `deprecatedAt`); SceneKit foi deprecado em todas as plataformas no Xcode 26. Xcode 26.3 "introduces support for agentic coding" e expõe o Xcode via MCP (`claude mcp add --transport stdio xcode -- xcrun mcpbridge`, projeto aberto). Xcode 27: "Agents can now boot simulators, install and launch apps, synthesize touch events, and capture screenshots to verify UI behavior"; `lldb-mcp`; `sudo xcrun mcp-server enable` para ambientes não assistidos; limitações: controle de jogo só no simulador de visionOS, Device Hub sem toque de dois dedos. Cenas SpriteKit não expõem árvore de acessibilidade → toques por coordenada + screenshot + canal de depuração (`debug_state.json`).

**RealityKit / Metal 4.** Apple recomenda RealityKit para novos projetos 3D. Game Porting Toolkit 4 traz as primeiras skills de agente oficiais da Apple (`translating-to-metal4-api`, `using-metalfx-temporal-upscaler`, `using-game-controller`…); na sessão 357 da WWDC26, sem as skills "the agent produced code that compiled but rendered incorrectly". Requisitos: Apple silicon, macOS 27, Xcode 27. Orçamento mobile da Apple (2018, reafirmado 2021): ≤ 100 mil polígonos, um conjunto de texturas 2048², ≤ 10 s de animação para AR Quick Look; RealityKit tem "a bit more wiggle room".

**Unity 6.3 LTS.** Plug-in oficial v0.1.8-beta (lido em 10/10/2026): "Available for Claude Code, Codex, and Grok", Unity 6+, 32 `SKILL.md` incluindo `implement-in-app-purchases`, `levelplay-unity-integration`, `2d-pixel-perfect`, `manage-sprite-atlas`, `create-2d-physics`, `optimize-audio`, `build-live-game`; "Many skills drive your open Unity Editor directly… through the Unity CLI"; aviso: "keep your project under version control". É a lista mais orientada a monetização mobile de qualquer engine. Unity AI: assets gerados levam metadados "AI-generated" e a declaração nas lojas é responsabilidade do desenvolvedor; créditos relatados como esgotáveis em horas [s]. apple/unityplugins (Apache 2.0): StoreKit 2, GameKit, Background Assets, CoreHaptics, GameController, PHASE; iOS 15.6+; novos StoreKit/Background Assets exigem Xcode 27 e Unity 2022 LTS+. Screenshot sem GUI: `-batchmode`/`-nographics` não renderizam; o Game Studios usa o player construído com um `MonoBehaviour` que chama `ScreenCapture.CaptureScreenshot`.

**Godot 4.7.** Texto-first (`.tscn`, GDScript). Godot AI (hi-godot, MIT, push em 10/10/2026): 46 ferramentas, `project_run` espera o jogo ficar vivo (`game_status` live/not_live), `test_run` roda suítes GDScript, `logs_read`, `editor_screenshot` do framebuffer do jogo; GDScript "parse-validated, hot-reloaded"; C# "text-only"; exige Godot 4.7+. Export iOS: "You must export for iOS from a computer running macOS with Xcode installed"; "The iOS simulator only supports the Compatibility renderer. Apple Silicon Macs can run iOS apps natively"; C# iOS "experimental… some limitations apply"; `export_project_only` "When combining Godot with Fastlane"; exports Metal restritos a A12+ por padrão desde 4.5.2 [s]; campos de privacy manifest no export. Godot 4.6 em 26/01/2026 e 4.7 em 18/06/2026 (1.265 correções) → fixar versão. Ban de contribuições por agente ao engine (30/06/2026) governa o repositório do Godot, não o seu jogo. Alternativa CLI sem MCP: `godot --path . --windowed --resolution WxH --write-movie out.png --quit-after 60 cena.tscn` (verificado pelo Game Studios em 4.6.1/Windows).

**Phaser / PixiJS + TypeScript.** "written in JavaScript or TypeScript, which models handle well, and it doesn't need an export step" [s]. Verificação pelo padrão da Anthropic: automação de navegador (Puppeteer MCP) com screenshots, "do all testing as a human user would"; limite conhecido: "Claude can't see browser-native alert modals through the Puppeteer MCP". Phaser Editor MCP (`scene-get-screenshot`) recomenda "training levels" rotulados porque "visuals… may not always be sufficient for the LLM". Para iOS: Capacitor (web view) — a 4.7 permite mini-jogos HTML5 sob 4.7.1–4.7.5; 4.2 e 4.3(b) continuam valendo. Não há caso verificado de jogo web empacotado com sucesso comercial na App Store.

**Three.js / Babylon.js.** Mesmo ciclo que Phaser. Dado de teto: o FPS que Matt Shumer fez o Claude Opus 5 construir (Three.js/WebGL2, ~55 mil linhas, 11 subsistemas, loop com críticos) parou "pouco acima de 5/10" no próprio crítico. fly.pieter.com (Three.js, multiplayer) é o único caso com receita relevante, e feito por desenvolvedor experiente. MCPs comunitários pequenos (babylonjs-mcp, 9 estrelas); PlayCanvas tem MCP oficial com `launch_start`, `capture_runtime`, `inject_input`.

**Unreal (excluído).** `.uasset` binário opaco; "the worst fit"; UE 5.8 MCP first-party experimental e sem autenticação por padrão; chongdashu/unreal-mcp parado desde abril/2025.
